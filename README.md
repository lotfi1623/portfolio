# Apex Dev Studio - Developer Team Portfolio

A premium, high-performance, and interactive portfolio website showcasing our software engineering team, projects, and competencies.

## The Engineering Team
- **Merah Lotfi Youcef** — Lead Full-Stack Developer
- **Messah Bilal Zinelabidin** — Frontend & UI/UX Engineer
- **Dellaoui Ayoub** — Backend & Systems Engineer

## Tech Stack
- **HTML5** & Semantic Elements
- **Vanilla CSS3** (Custom Grid layouts, Flexbox structures, Glassmorphic panels, and Keyframe Animations)
- **Vanilla JavaScript** (Dynamic IDE config typist, Intersection scroll reveals, and filterable skill matrices)

## Core Features
* **Interactive Code IDE Terminal**: Simulates a live-typed configuration schema representing the team on the hero banner.
* **Filterable Stack Showcase**: Dynamic tabs allow visitors to filter competencies by Frontend, Backend, or Systems.
* **Responsive Layout**: Designed from the ground up to support smartphones, tablets, and desktops.
* **Modern Tech Aesthetics**: Void-black background featuring grid blueprint templates and neon radial color glows.

## Files
- `portfolio.html` — The main portfolio website with embedded styles and JavaScript logic.
- `portfolio` — An extensionless synchronized duplicate of the main page.
